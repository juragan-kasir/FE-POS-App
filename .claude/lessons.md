# Lessons

- [i18n] `t` from useTranslation keeps its identity when the http backend finishes loading — a useMemo snapshot of t() calls with `[t]` deps freezes raw keys after a full reload; always include `ready` in the deps (or call t() inline). (2026-10-28)
- [workflow] A bug report about "copywriting X" usually means the raw key X is rendering (translation resolution failure) — fix resolution, never delete the copy. (2026-10-28)
- [components] Hide a store filter by returning null at the label-and-control wrapper (`StoreFilterField`), not only inside `StoreFilter` — the page-owned label otherwise stays visible for single-store users. (2026-10-29)
- [components] A `TableToolbar` filter wrapper still takes a `flex-1` slot when its child renders null; add `empty:hidden` so hiding the store filter also collapses its empty grid column. (2026-10-30)
- [auth] Remember-me spans cookie expiry, a localStorage user copy, and the shared `useActiveSessionRedirect` hook (used by both `/` and `/login`) — sessionStorage is empty after a browser restart. (2026-11-05)
- [auth] Login lives at `LOGIN_PATH`, and `/` is the public landing page — session teardown must target `LOGIN_PATH`, otherwise the logout/expiry notice never shows. (2026-11-05)
- [components] Icon-only delete buttons use variant="ghost" + text-destructive, not variant="destructive" — the destructive variant paints a red icon on a red background (hit in product, GR, supplier and promo forms). (2026-10-31)
- [components] `Button asChild` throws here because Button always renders two child slots for Slot; style anchors with `buttonVariants()` instead. (2026-11-05)
- [styling] `cn()` (tailwind-merge) drops `leading-*` when a later `text-[size]` class overrides the size; restate the leading next to the override. (2026-11-05)
- [react] React 18 warns on `fetchPriority` while ESLint rejects `fetchpriority` in JSX; pass the lowercase attribute through a spread object. (2026-11-05)
- [copy] Marketing copy in Indonesian is casual-professional: `kamu`, concrete owner scenes, no `Anda`, and each line says something new; test every line by asking whether an Indonesian would say it aloud, and rewrite English-shaped sentences (`kami mulai dari sana`, `bahkan saat`, `akan kami tampilkan`) instead of translating them. The app UI keeps its `Anda` voice. (2026-11-05)
- [i18n] Buttons on language-switchable pages use fixed widths and nav uses `1fr auto 1fr`; content-sized controls shift the layout when ID/EN strings differ. (2026-11-05)
- [perf] A `<link rel=preload as=fetch>` is only reused when its URL (including `?v=`) and `crossorigin` match the real fetch; otherwise the file downloads twice. Measure with throttling on the production build. (2026-11-05)
- [styling] Keep the landing mono font to receipts only; two typefaces carry the page, and mono on labels reads as an unrelated third voice. (2026-11-05)
- [copy] Never mention company size or being small in marketing copy; make no enterprise claims either, and lead with what the team does for the owner. (2026-11-05)
- [deploy] Every new `VITE_*` var needs an `ARG` in `Dockerfile` and a `--build-arg` in `docker-build.sh`; a host variable the Dockerfile does not declare never reaches `vite build`, so the feature silently uses its fallback. (2026-11-05)
- [routing] Keep the `*` route outside `DashboardLayout` and gate logged-in chrome (`Support`, sidebar) on `readActiveSessionRole`; a nested catch-all shows admin UI to public visitors. (2026-11-08)
- [errors] A rejected `React.lazy` stays rejected, so a chunk failure needs a full reload, never an in-place retry; and boundaries must call `reportRenderError` because Sentry does not see errors React caught. (2026-11-08)
- [components] `Loading` defaults to `fullscreen`, which portals an overlay; pass `fullscreen={false}` inside page layouts, or use `PageLoader`. (2026-11-08)
- [seo] A new public page needs an `Allow` line in `public/robots.txt` and a `public/sitemap.xml` entry, because robots is an allowlist. (2026-11-08)
- [tests] Several tests read source files as text (`index.html`, `App.jsx`, layouts); grep `src/tests` for the exact line before changing it, because lint and build will not catch the break. (2026-11-08)
- [i18n] `ready` from `useTranslation` can be true before the locale file arrives (seen at 143 ms against a 2.5 s fetch); use `isLocaleLoaded(language)` when raw keys must never show. (2026-11-08)
- [tooling] A second worktree directory (`.worktrees-fe/`, next to `.worktrees/`) must be added to `.gitignore` *and* Jest `modulePathIgnorePatterns` together — one without the other breaks `npm test` (haste map) or stages embedded gitlinks into the commit. (2026-11-07)
